# A-2 — Applicabilité de NF P18-418 dans la chaîne EN 13791 (audit final)

Statut : **AMBIGUÏTÉ NORMATIVE MAINTENUE — MOTEUR INCHANGÉ**
Dernière revue : finalisation du module Carottage.

## 1. Chaîne de calcul Mode A (inchangée, auditée)
1. Section A = π·D²/4 (mm²)
2. fcore = F(kN)·1000 / A (MPa) → **valeur brute**
3. K(L/D) — table NF P18-418, domaine 1,00 ≤ L/D ≤ 2,00 (interpolation linéaire) :
   1,00 → 0,90 ; 1,25 → 0,96 ; 1,50 → 1,00 ; 1,75 → 1,02 ; 2,00 → 1,03
4. fcorr = K · fcore → **valeur corrigée**, géométrie de référence cylindre 16×32
5. Masse volumique ρ = m / V (kg/m³)

Hors du domaine [1,00 ; 2,00] : carotte **hors domaine**, aucun fcorr produit (aucune extrapolation).

## 2. Donnée réellement consommée par le Mode B
Le Mode B lit `fcorr` (valeur brute non arrondie, champ `fcorr_raw`) et **ne recalcule jamais**
section, fcore, L/D ni K. Vérifié dans `src/lib/essais/normative/` : aucun appel à une fonction
de correction d'élancement, aucune multiplication par K.

- **EN 13791:2007** → consomme fcorr 16×32. ✅ cohérent : la version 2007 raisonne sur des
  résistances ramenées à une éprouvette de référence.
- **EN 13791:2019** → consomme également fcorr 16×32. ⚠ voir § 4.

## 3. Double correction — vérification
| Point de contrôle | Résultat |
| --- | --- |
| K appliqué en Mode A | 1 seule fois (`computeCarotte`) |
| K appliqué en Mode B | jamais |
| fcorr recalculé en Mode B | non (lecture seule de la valeur archivée) |
| K archivé dans la traçabilité | oui (`k`, `k_methode`, `k_methode_version`) |
| Relecture d'une évaluation figée | affichage des valeurs archivées, aucun recalcul |

→ **Aucune double correction. Aucune correction L/D appliquée deux fois.**

## 4. EN 13791:2019 — point non tranché
Le § 6/§ 8 de la version 2019 considère la carotte prélevée in situ, avec 1,0 ≤ L/D ≤ 2,0,
comme **directement représentative** de la résistance in situ : aucune conversion vers un
cylindre 16×32 n'est requise par le texte.

Appliquer NF P18-418 en amont d'une évaluation 2019 est donc une **pratique nationale
surnuméraire** : ni interdite, ni normativement exigée par la version 2019.

Effet quantitatif borné par la table : facteur K ∈ [0,90 ; 1,03].
- L/D < 1,50 → K < 1 → la chaîne actuelle **sous-estime** légèrement la résistance (conservatif).
- L/D > 1,50 → K ∈ ]1,00 ; 1,03] → **surestimation ≤ 3 %**.

Il n'existe donc **pas** de biais systématique de surestimation, mais un écart possible de +3 %
au maximum pour les carottes élancées. Ce point ne peut pas être tranché sans une décision
documentaire (texte officiel EN 13791:2019 + annexe nationale applicable en Algérie).

## 5. Décision retenue (inchangée)
- Mode A inchangé : produit toujours fcorr 16×32 (NF P18-418).
- Mode B consomme cette valeur, sans jamais la recorriger.
- Référentiel 2019 sélectionné → encart explicite dans l'interface **et** avertissement archivé
  dans l'évaluation (norme, version, clause, formule, méthode K et sa version).
- Aucun mélange de versions : un seul évaluateur par évaluation.

## 6. Ce qui manque pour trancher définitivement
1. Le texte intégral d'EN 13791:2019 § 6 et § 8 (domaine d'application des résistances d'entrée).
2. L'annexe nationale / doctrine applicable (maintien ou non de NF P18-418 en amont de 2019).
3. Une décision d'entreprise documentée sur la convention retenue par le laboratoire.

## 7. Option future (non implémentée)
Ajouter au Mode B un sélecteur d'entrée : « fcorr 16×32 (NF P18-418) » **vs** « fcore brut »
lorsque le référentiel 2019 est choisi. Cette option n'impacterait pas le Mode A et n'est pas
mise en œuvre tant que le point 6 n'est pas tranché.
