# A-2 — Applicabilité de NF P18-418 dans la chaîne EN 13791:2019

## 1. Chaîne de calcul Mode A (inchangée)
1. Section A = π·D²/4 (mm²)
2. fcore = F(kN)·1000 / A (MPa)
3. K(L/D) selon NF P18-418, domaine 1,00 ≤ L/D ≤ 2,00 (interpolation linéaire)
4. fcorr 16×32 = K · fcore
5. Masse volumique ρ = m / V (kg/m³)

Depuis les corrections A-4/A-5 :
- aucun cas particulier « K = 1 si L/D = 2 » (la table donne K = 1,03 en L/D = 2,00, sans rupture) ;
- hors du domaine [1,00 ; 2,00], aucune extrapolation : la carotte est **hors domaine** et aucune fcorr n'est produite.

## 2. EN 13791:2007
La version 2007 raisonne sur des résistances ramenées à une éprouvette de référence.
La correction d'élancement NF P18-418 est **cohérente** avec cette chaîne : fcorr 16×32 est
l'entrée attendue des critères du § 8.1.

## 3. EN 13791:2019
Le § 6/§ 8 de la version 2019 considère la carotte prélevée in situ, avec 1,0 ≤ L/D ≤ 2,0,
comme **directement représentative** de la résistance in situ : aucune conversion vers un
cylindre 16×32 n'est requise.

Conséquence : appliquer NF P18-418 avant l'évaluation 2019 est une **pratique nationale
surnuméraire**. Elle n'est ni interdite ni normativement exigée ; elle modifie légèrement les
valeurs d'entrée (±10 % au plus, selon L/D).

## 4. Décision retenue dans l'application
- Le Mode A reste inchangé : il produit toujours fcorr 16×32 (NF P18-418).
- Le Mode B **consomme** cette valeur sans jamais la recalculer ni la corriger une seconde fois.
- Lorsque le référentiel 2019 est sélectionné, un encart explicite signale l'hypothèse à
  l'utilisateur, et la traçabilité (norme, version, clause, formule, méthode K et sa version)
  est archivée avec l'évaluation.
- Aucune version n'est mélangée : chaque évaluation applique un évaluateur unique.

## 5. Recommandation
Pour une évaluation 2019 « stricte », renseigner en Mode A des carottes dont L/D est proche de
la valeur réelle et considérer, en analyse critique, la variante sans correction d'élancement.
Cette variante pourra être ajoutée ultérieurement comme option d'entrée du Mode B
(« fcore brut » vs « fcorr 16×32 ») sans impact sur le Mode A.
